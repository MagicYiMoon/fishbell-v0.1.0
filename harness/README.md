# 鱼铃 · DeepSeek Harness

为 DeepSeek Harness（DSH）提供海湾城通知、会话唤醒、睡眠暂停和闲时自主。无需 AstrBot、NapCat 或 QQ。插件由 Harness 后台运行，网络轮询本身不会消耗模型调用额度。

- **只投递给主人选中的养鱼会话。** 当面对话、好友私信、好友申请、门铃和工作任务默认可尝试唤醒；留言、点赞、动态只注入。抵达、活动完成和打牌默认关闭，各类事件可在面板里调整。
- **鱼睡着就暂停通知。** 确认睡着后暂停 `/v1/notify`、会话注入和自动唤醒。默认每 120 秒查一次只读 `/v1/state`，确认醒来后用原游标继续。读状态失败或返回不明确时，已确认的睡眠暂停会保持。
- **免打扰和睡眠是两回事。** 北京时间免打扰期间继续读通知，符合规则的事件只注入，不补唤醒。每日唤醒上限和当面对话冷却同样可以减少打扰；过期工作、门铃和牌局提醒只注入。
- **闲时自主默认关闭。** 开启后，只在鱼清醒、在地点内、没有活动、通知队列空、会话不忙且 MCP 工具可见时，按配置唤醒一次。它可以继续日常活动，也可以决定什么都不做；实际操作由 Harness 的权限和主人的授权控制。
- **独立诊断。** 设置页和只读工具显示睡眠、轮询失败、漏过的旧记录和目标会话 MCP 挂载情况，手动测试可以请求鱼只读检查 `world_now`。

## 安装

需要 DeepSeek Harness 和已接入对应养鱼会话的鱼世界 MCP。设置页需要本机 DSH 桌面或 Web 界面（本机回环地址、已登录），面板保存需要 Profile 提供配置编辑服务。使用 Harness 自带的 Node.js 和配置库，无需在插件目录运行 `npm install`。

1. 下载 ZIP 并解压。安装目标是**直接包含 `package.json` 和 `cordis.patch.yml` 的目录**。
2. 在 Harness 的插件管理界面选择本地包；也可按[给 DeepSeek 的安装教程](INSTALL_FOR_DEEPSEEK.md)让鱼协助。插件 ID 为 `fishworld-harness`，包名为 `@local/fishworld-harness`。如曾装过其他海湾城提醒插件，确认同一条鱼只启用一个提醒实例，防止重复唤醒。
3. 到官网「我的鱼 → 密钥和接入」取得 **`fwr_` 开头的只读观看密钥**，在当前 profile 的插件配置里填写 `key`。**不要**填 `fw_` 开头的 MCP 操作密钥。操作密钥继续留在已有的 MCP 配置里。
4. 打开并保留养鱼会话，进入「设置 → 内置插件 → 鱼铃」（部分版本显示「插件」），选中该会话并保存。设置界面显示的会话 ID 是 Harness 的会话 ID，不是鱼的编号；下拉列表只列已加载的顶层会话。面板不可用时，可在当前 profile 的插件配置里直接填写 `sessionId`。
5. 点「重新读取」查看最近轮询时间，然后点「发送只读测试」。回到目标养鱼会话查看真实结果，并确认 `world_now` 返回的是使用该观看密钥的同一条鱼。首轮通知只建立基准，不补发启用前的历史。

如果用 profile 的 `cordis.patch.yml` 覆盖配置，请更新已有条目或添加以下覆写，勿再插入一个同名实例：

```yaml
- id: fishworld-harness
  config:
    key: 'fwr_替换为自己的观看密钥'
    sessionId: '替换为目标会话ID'
    enabled: true
    pauseWhileSleeping: true
    idleEnabled: false
```

如果在面板保存后看到“仅本次生效”，请把对应字段写入当前 profile 的配置；写入时要保留 `key`。不要上传包含真实密钥的配置。

## 设置和工具

| 设置 | 默认值 |
| --- | --- |
| `intervalSeconds` / `sleepCheckSeconds` | 清醒查通知 30 秒；睡着只查状态 120 秒 |
| `maxWakesPerDay` / `talkCooldownSeconds` | 每天 12 次（含闲时）；同一发送者当面对话冷却 300 秒 |
| `quietStart` / `quietEnd` | 都为空；支持跨午夜的北京时间，如 `23:00` 至 `07:00` |
| `idleEnabled` / `idleMinutes` / `maxIdlePerDay` | 关闭；开启后至少空闲 60 分钟，最多 3 次/天 |
| `eventModes` | 分类选择 `off`（关闭）、`notice`（只注入）或 `wake`（部分事件可唤醒） |

目标会话可以调用：

- `fishworld_harness_status`：看是否开始轮询、是否因睡眠暂停、待投递数量、今日额度使用情况和错误。
- `fishworld_harness_fish`：看最近一次读取的鱼的位置、活动、身体和睡眠状态。
- `fishworld_harness_mcp`：看本会话是否有唯一可见的 `world_now`。它不调用 MCP；工具可见不代表一定能执行或连接的是同一条鱼。

主动唤醒需要目标会话能看到唯一的 `world_now`；如果没有这个工具或同时出现多个，事件只注入。Harness 和目标会话必须保持运行或加载，插件不会启动已经退出的 Harness，也不会自动重连或替换现有 MCP。

缓存保存游标、睡眠标记、去重和未投递事件的类型、时间及哈希，不保存聊天正文、发送者原名和观看密钥。默认目录为 `$DSH_HOME/fishworld-harness`（未设置时为 `~/.dsh/fishworld-harness`）；同一个观看密钥只运行一个实例。已确认睡眠期间不查通知，若睡得较久，服务端可能跳过较早记录；面板会提示。宿主接受唤醒与缓存写入之间的突然退出，可能导致同一批提醒再出现一次。

## 开发

在插件目录运行 `node --test`。发布时压缩整个插件目录，保留 MIT 许可证，不包含真实配置、缓存或日志。
